# Software Lantern — Keyword Map (Phase 2)

## ⚠️ Data Honesty Note — Read Before Using This Document

**No keyword-volume tool was used to produce this document.** There is no Ahrefs, SEMrush, Google Keyword Planner, or Google Search Console access in this environment. Every "Commercial Intent" and "Estimated Priority" judgment below is a **qualitative, reasoned estimate** based on:

- The buyer personas, roles, and triggers defined in `/docs/ICP.md`
- General knowledge of B2B SaaS / regulatory-compliance search behavior
- A round of web research into how EUDR, Battery Passport/DPP, and Fashion PLM vendors and content actually describe these categories today (terminology-only — no volume/ranking data was available or is claimed)

**No specific search-volume numbers are given anywhere in this document, because none are known.** Priority is expressed only in qualitative terms (High/Medium/Low commercial intent; P1–P3-style priority bands), never as a fabricated number.

**Before this map drives significant content investment, validate it against real data**: once the site has any organic traffic, cross-check against Google Search Console query data; before that, a proper keyword tool (Ahrefs, SEMrush, or even Google Keyword Planner's directional volume bands) should replace the estimates here. Treat this document as a **directional starting point that reflects buyer-intent reasoning, not a final source of truth**.

**Terminology grounding (from research, not assumption):**
- "EUDR compliance software," "EUDR software," and "EUDR due diligence software" are all real, interchangeable-ish category labels vendors and buyers actually use. "Deforestation regulation software" is *not* real market language and is deliberately not targeted.
- "Battery Passport" and "Digital Product Passport (DPP)" are **related but not synonymous** — DPP is the broad, multi-category regulatory/technology umbrella (textiles, furniture, electronics, batteries, etc.); "Battery Passport" is the battery-specific implementation and matches the EU Battery Regulation's own terminology. This map treats "battery passport" as the primary term (best buyer-fit for Software Lantern's battery-focused ICP) and "digital product passport" / "DPP" as a secondary, carefully-qualified term (a bare "DPP software" searcher may be evaluating a multi-category platform, not necessarily for batteries).
- "Fashion PLM" / "apparel PLM" is genuinely how that market self-identifies — confirmed via real vendor and content titles. Plain "PLM software" is a real but much broader, wrong-audience term (general/automotive/industrial PLM vendors dominate it) — this validates the audit's finding that `/plm` should retarget.
- The dominant real comparison-content pattern observed across all three categories is "best [category] software/tools" and "[category] software comparison" (listicle-style), not "[vendor] alternatives" or "X vs Y" head-to-head framing — the latter patterns appear in the task brief as examples but were not strongly evidenced in this round of research, so they're included below at lower confidence/priority.

Each category table uses these columns: **Keyword | Search Intent | Buyer Persona | Industry | Commercial Intent | Priority | Recommended Page | Content Type | Primary/Secondary | Notes**.

- **Commercial Intent** — High/Medium/Low, qualitative only (see data honesty note).
- **Priority** — P1 (build/target first) / P2 (build once P1 pages exist) / P3 (later, only if P1/P2 prove out).
- **Recommended Page** — an existing page where possible; where the recommended page doesn't exist yet, it's marked `(new — Phase 4 pre-approved)` for the two confirmed category-page gaps, or `(future — not yet justified)` for anything else, per the brief's anti-proliferation instruction.
- Closely-related keyword variants (e.g. the same pattern across 6 commodities) are **consolidated into one row** with variants listed, rather than atomized into near-duplicate rows — this mirrors the brief's own "one strong page beats many thin pages" instruction applied to keyword planning, not just page planning.
